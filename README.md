# Vega-Arabic (Vega-SK) — Arabic Providers Bundle

عدد البروفايدرز: 38

## البنية
manifest.json          → قائمة البروفايدرز (يقرأه تطبيق Vega)
dist/<provider>/*.js   → ملفات البروفايدر المجمّعة (catalog/posts/meta/stream/episodes)
assets/<provider>.png  → الأيقونات

## طريقة الرفع على GitHub (alowedan/vega-arabic)
1. ادخل ريبوك: https://github.com/alowedan/vega-arabic
2. Add file → Upload files → اسحب كل محتويات هذا المجلد (مع الحفاظ على البنية)
3. Commit changes

## الإضافة في تطبيق Vega (الموبايل)
- الإعدادات → Provider Manager → (+) → الصق الرابط الكامل:
  https://github.com/alowedan/vega-arabic
- أو الاسم المختصر: alowedan  (لو سمّيت الريبو vega-providers)
