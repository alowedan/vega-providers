## 📖 عن المشروع

مستودع يجمع **38 مصدر بث عربي** يعملون مباشرةً على تطبيق **Vega** (نسخة الموبايل و Desktop)، شاملين أشهر مواقع الأفلام والمسلسلات والأنمي وقنوات البث المباشر في الوطن العربي.

كل بروفايدر تم تحويله من صيغة CloudStream (`‎.cs3‎`) إلى صيغة Vega الأصلية (`catalog.js / posts.js / meta.js / stream.js`) مع الحفاظ على نفس منطق العمل والمصادر.

> 💡 **ملاحظة:** ملفات `‎.cs3‎` الأصلية هي Dalvik bytecode مُجمّع (كود أندرويد خام) ولا يمكن تشغيلها مباشرة في Vega. تمت إعادة كتابة كل بروفايدر من الصفر بالاعتماد على نفس APIs المواقع الأصلية.

## 📥 التثبيت على تطبيق Vega

### الطريقة الأولى: الاسم المختصر (الأسرع)

> بعد تسمية الريبو `vega-providers`، الاسم المختصر `alowedan` يشتغل فوراً.

```
1. افتح تطبيق Vega
2. اذهب إلى: الإعدادات ← Provider Manager
3. اضغط زر (+) في الأعلى
4. اكتب الاسم المختصر:  alowedan
5. اضغط Add — ستظهر كل المصادر الـ 38
```

## ❓ أسئلة شائعة

<details>
<summary><b>🔍 كيف أضيف المصدر لتطبيق Vega؟</b></summary>

افتح تطبيق Vega → الإعدادات ← Provider Manager ← زر (+) ← اكتب `alowedan` ← Add.

أو الصق الرابط الكامل: `https://github.com/alowedan/vega-providers`

</details>

<details>
<summary><b>⚙️ لماذا الاسم المختصر هو alowedan وليس Vega-SK؟</b></summary>

تطبيق Vega يحوّل الاسم المختصر داخلياً إلى `{username}/vega-providers/main` — يعني:
- الاسم المختصر = اسم مستخدم GitHub
- اسم الريبو يجب أن يكون `vega-providers` بالظبط

لذلك بعد تسمية الريبو `vega-providers`، الاسم المختصر `alowedan` يشتغل فوراً.

لو تريد اسم "Vega-SK" بالظبط، تحتاج إنشاء حساب GitHub جديد بهذا الاسم ورفع نفس المحتوى في ريبو `vega-providers` تحته.

</details>

<details>
<summary><b>🌍 بعض المصادر لا تعمل في السعودية، ما الحل؟</b></summary>

بعض المواقع محجوبة في السعودية. الحلول:
- **للموبايل**: استخدم تطبيق ByeDPI أو أي VPN
- **للـ Desktop (Vega Desktop)**: استخدم ByeDPI بدلاً من WARP (WARP يحجب طلبات البروفايدرز)
- أو جرّب مصدراً آخر لنفس المحتوى (معظم الأفلام متوفرة على 3-4 مصادر مختلفة)

</details>

<details>
<summary><b>🔄 كيف يتم تحديث المصادر؟</b></summary>

عند تعطّل أي مصدر، يتم إصلاحه في الريبو الأصلي `Zenda-Cross/vega-providers` ثم يُنسخ التحديث لهذا الريبو. كل ما عليك فعله في Vega هو سحب التحديث من Provider Manager.

</details>

<details>
<summary><b>🎬 هل يمكن تحويل هذه المصادر لـ Stremio؟</b></summary>

ممكن، لكنه مشروع منفصل تماماً. Stremio يحتاج سيرفر HTTP (Node.js) يرد على endpoints بصيغة Stremio، بينما Vega يقرأ ملفات JS مباشرة. لو مهتم، افتح issue وسنبدأ العمل عليه.

</details>

<details>
<summary><b>📱 هل يعمل على Vega Desktop أيضاً؟</b></summary>

نعم، نفس المستودع يعمل على نسخة الموبايل و Desktop. لنسخة Desktop استخدم ملف `urls.json` الموجود في الريبو.

</details>
